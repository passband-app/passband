Passband MCP vs Superhuman MCP · checked October 2026

A briefing, or a remote control.

Both connect your AI agent to your email over MCP. They make opposite bets. Superhuman's server lets your agent operate the mailbox: 28 documented tools that read, search, draft, send, trash, label and schedule across every inbox you link. Passband's Agent MCP hands your agent what Passband's triage already worked out: what needs you and why, what is due, what is on its way, and the instructions you gave it for each sender. Sign-in codes and password reset links never reach it.

02 · WHAT YOUR AGENT GETS

Your agent, briefed.

Passband reads every message as it arrives and decides what needs you. Agent MCP hands your agent that judgment, so it starts from an answer instead of a pile of mail. Seven tools, in plain terms:

get_inbox_updates

What needs you, ranked

The threads Passband put in front of you, in order. Each says whether it needs you or is waiting on someone else, what it asks you to do and by when, and the evidence behind the call.

get_thread

The whole conversation

Any thread, oldest message first, as plain text. No HTML and no recipient addresses.

search_mail

Search that finds the old one

Keyword and meaning together, tilted toward recent mail, or ranked on relevance alone when you are hunting. Results come back as one-line summaries, and your agent opens the thread it wants.

get_deadlines

What is due

Bill due dates and open deadlines in one list, in date order, with amounts and a past-due flag. A date stays a date; nothing invents a time.

get_shipments

What is on its way

Packages grouped by order, with the carrier's latest status, including deliveries that never had a tracking number.

list_sender_rules · set_sender_rule

Your standing instructions

Write a rule for a sender in Passband, like “only tell me when the amount changes,” and your words travel with that sender's mail to your agent. Your agent can read your rules and set new ones, inside Passband.

03 · WHAT NEVER REACHES THE AGENT

Sign-in codes stay sealed.

Mail carrying a live sign-in code or a password reset link never reaches your agent. It is not redacted; it is absent. Ask for it by id and the answer is the same not-found as a message that does not exist, so even its existence stays in Passband.

Passband's triage decides which messages carry a code or a reset link, and a message it has not assessed yet stays closed to agents until it has. A thread is readable only if every message in it is. A routine “new sign-in to your account” notice with no code in it may still be readable. The full rules are in the threat model.

Superhuman MCP

The tools in reach include sending.

An email written to steer an agent lands among the mail it reads. Through Superhuman's server, the tools that agent can call include send_draft, trash_thread, unsubscribe with block, and update_personalization, which changes the facts your drafts are written from, across every linked inbox.

Whether a call waits for you is a setting in your AI client. Superhuman's help article advises turning confirmation on for send_draft, as it can send emails instantly without any delay, and calls confirmation a safety net, not a permanent setting.

Passband Agent MCP

Worst case today: one sender rule, logged.

The one tool that writes changes a sender rule inside Passband, and it applies only to mail that arrives after it. None of the seven tools writes to Gmail.

Every rule an agent writes is recorded in the same step as the rule itself. If the record cannot be written, neither is the rule.

This is not hypothetical for email AI. In January 2026, PromptArmor showed that one received email could make Superhuman's built-in AI exfiltrate “partial contents from over 40 emails with a single AI response.” That was Superhuman's built-in AI, not its MCP server, and no attack on the MCP server has been published. Superhuman responded quickly, in what PromptArmor called “a security response in the top percentile.”

04 · HOW IT CONNECTS

Add it where your agent already lives.

Passband for Mac writes the exact setup for your agent in Settings, Agents, with your address already in it. On hosted, which is rolling out now, your agent opens a browser and you sign in with the Google account of the mailbox. On self-host, the address stays on your computer or your tailnet. Either way, there is no token to paste.

Claude

Add Passband as a custom connector: Customize, Connectors, paste the address. hosted

OpenClaw

One openclaw mcp add passband on the machine your gateway runs on.

Hermes Agent

A few lines in ~/.hermes/config.yaml, then /reload-mcp.

Claude Code

claude mcp add --transport http passband <address>

Codex

codex mcp add passband --url <address>

Cursor

One entry in ~/.cursor/mcp.json.

Claude's custom connectors reach Passband from Anthropic's servers, so they need hosted. On self-host, Claude Desktop connects through mcp-remote. Any other client that takes a remote MCP server works the same way.

05 · PRICE

What it costs to start.

Superhuman MCP

$33 to $40 per user per month

MCP access starts at the Business plan: $40 per user per month, or $33 billed annually. Superhuman's help article: The MCP Server is not available on the Starter plan.

Passband Agent MCP

No plan on self-host

The daemon is MIT licensed and Agent MCP is part of it. Triage uses a model key you supply, or runs on local rules with none. Hosted Passband is invitation-only while it is in preview.
