Passband MCP vs Slashy MCP Checked October 2026

A briefing, or a remote control.

Both connect your AI agent to your email over MCP. They make opposite bets. Slashy's server hands your agent Slashy's own toolset: it can “draft, send, reply, schedule, label, and attach files,” create calendar events, research your contacts and set up automations. Passband's Agent MCP hands your agent what Passband's triage already worked out: what needs you and why, what is due, what is on its way, and the instructions you gave it for each sender. It writes mail only as far as you allow: out of the box a draft you send yourself, and sending only if you turn it on. Sign-in codes and password reset links never reach it.

02 · WHAT YOUR AGENT GETS

Your agent, briefed.

Passband reads every message as it arrives and decides what needs you. Agent MCP hands your agent that judgment, so it starts from an answer instead of a pile of mail. Seven tools, always there, in plain terms:

get_inbox_updates

What needs you, ranked

The threads Passband put in front of you, in order. Each says whether it needs you or is waiting on someone else, what it asks you to do and by when, and the evidence behind the call.

get_thread

The whole conversation

Any thread, oldest message first, as plain text. No HTML and no recipient addresses.

search_mail

Search that finds the old one

Keyword and meaning together, tilted toward recent mail, or ranked on relevance alone when you are hunting. Results come back as one-line summaries, and your agent opens the thread it wants.

get_deadlines

What is due

Bill due dates and open deadlines in one list, in date order, with amounts and a past-due flag. A date stays a date; nothing invents a time.

get_shipments

What is on its way

Packages grouped by order, with the carrier's latest status, including deliveries that never had a tracking number.

list_sender_rules · set_sender_rule

Your standing instructions

Write a rule for a sender in Passband, like “only tell me when the amount changes,” and your words travel with that sender's mail to your agent. Your agent can read your rules and set new ones, inside Passband.

What it may write is your call.

Out of the box an agent can leave you a draft, and nothing more. In Passband, under Settings, Agents, “What your agent may write” moves that line per mailbox, and the door offers only the tools your level allows.

no extra tools

Read only

The seven tools above and nothing else. The agent cannot leave a draft or send a message.

create_draft · open_draft

Drafts only default

The agent leaves a draft in Passband, marked from your agent, for you to read, edit and send, or discard. It can ask your Mac to bring the draft up in the composer, where only the send button sends it. Nothing leaves your mailbox.

send_email

Send, with your approval

The agent sends from your address through the same guarded, logged pipeline your own mail takes. It is told to show you each message and wait for your yes in its chat, which Passband cannot see: an instruction to the agent, not a lock. Drafts only is the hard stop.

At every level an agent can reply only to mail it can read, writes to the sender address it was shown and copies nobody it did not name, attaches and forwards nothing, never touches a draft you are writing, and never holds your Gmail credential. The full rules are in the threat model.

03 · WHAT NEVER REACHES THE AGENT

Sign-in codes stay sealed.

Mail carrying a live sign-in code or a password reset link never reaches your agent. It is not redacted; it is absent. Ask for it by id and the answer is the same not-found as a message that does not exist, so even its existence stays in Passband.

Slashy MCP

The tools in reach include sending.

An email written to steer an agent lands among the mail it reads. Through Slashy's server, the tools that agent can call include send_email, with files attached from your Drive, and the ones that label mail, schedule sends and create automations.

Slashy's guide says so itself: Prompts that say “send” will send immediately. The skill file it ships tells the agent to assume “draft” unless the user explicitly says “send”, which is an instruction to the model, not a lock.

Slashy says it sanitizes and isolates incoming email content from system instructions before it reaches any model, and its Read Mode stops its own agent from sending. Its MCP docs do not say whether either applies to an outside agent you connect.

Passband Agent MCP

Worst case out of the box: a rule, or a draft you have to send.

A steered agent can change a sender rule inside Passband, which applies only to mail that arrives after it, or leave a draft, marked as the agent's, that goes nowhere until you press send. Nothing it can do out of the box sends mail.

Turn on “Send, with your approval” and the worst case grows to a message sent from your address. The agent is told to show you each one and wait for your yes, Passband's outbound guard reads all of it for anything that looks like a password or a key with no override, and every send is logged. But the yes happens in the agent's chat, where Passband cannot check it. Drafts only is the hard stop.

Every rule, draft and send by an agent is recorded as the agent's. A rule or draft whose record cannot be written is not written.

04 · HOW IT CONNECTS

Add it where your agent already lives.

Passband for Mac writes the exact setup for your agent in Settings, Agents, with your address already in it. On hosted, which is rolling out now, your agent opens a browser and you sign in with the Google account of the mailbox. On self-host, the address stays on your computer or your tailnet. Either way, there is no token to paste.

Claude

Add Passband as a custom connector: Customize, Connectors, paste the address. hosted

OpenClaw

One openclaw mcp add passband on the machine your gateway runs on.

Hermes Agent

A few lines in ~/.hermes/config.yaml, then /reload-mcp.

Claude Code

claude mcp add --transport http passband <address>

Codex

codex mcp add passband --url <address>

Cursor

One entry in ~/.cursor/mcp.json.

Claude's custom connectors reach Passband from Anthropic's servers, so they need hosted. On self-host, Claude Desktop connects through mcp-remote. Any other client that takes a remote MCP server works the same way.

05 · PRICE

What it costs to start.

Slashy MCP

$25 to $30 a user a month

The server needs a Slashy account. Professional is $30 a user a month, or $25 billed annually, after a 7-day trial that takes a card. Sign-in is OAuth 2.1 with PKCE, with no key to paste.

Passband Agent MCP

Free in Beta

The daemon is MIT licensed and Agent MCP is part of it. Triage uses a model key you supply, or runs on local rules with none. Hosted Passband is invitation-only while it is in preview.
